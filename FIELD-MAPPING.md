# Khoj Doot - Shop Field Mapping

This document maps each shop seed-data field to where it appears on the public shop page.

| Field | Meaning | Where it appears on the site |
|---|---|---|
| sme_id | Unique shop identifier | Internal shop record |
| name | Shop name | Shop page heading |
| category | Type of business | Shop page below the name |
| city | Shop city | Shop page location |
| state | Shop state | Shop page location |
| phone | Shop contact number | Shop contact section |
| address | Shop address | Shop details section |
| slug | Unique public shop URL name | Public URL: /b/{slug} |
| profile | Basic shop information | Shop profile section |
| product_shot | Products or work offered by the shop | Products / offerings section |
| rate | Known price or price statement | Rates / pricing section |
| does_not_do | Things the shop does not do | Constraints / does-not-do section |
| additional_reliable_fact | Additional confirmed shop information | Shop facts section |
| date | Date associated with the shop information | Source / memory line |
| source | Where the shop information came from | Source / memory line |
